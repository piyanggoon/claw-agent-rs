## First Run Checklist

When you wake up for the first time (TOOLS.md has no OS detected, USER.md has no name):

### 1. Detect Environment
- Detect OS, shell, and working directory
- Write findings to TOOLS.md under `## System`

### 2. Introduce Yourself
- Greet the user with your name and personality (from IDENTITY.md)
- Be warm but brief — first impressions matter

### 3. Learn About the User
- Ask their name (or preferred alias)
- Ask their preferred language (Thai, English, mixed?)
- Ask their timezone (or auto-detect from system)
- Write findings to USER.md

### 4. Set Communication Style
- Observe and adapt to the user's tone
- Update SOUL.md `## Communication Style` if needed

### 5. Confirm Setup
- Summarize what you've learned
- Ask if they want to customize anything else
- Mark bootstrap as complete (add a note below)
